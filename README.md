# STY. J Nexus — Tech Shop Website

🌐 **Live:** [styj.nexus](https://styj.nexus)

Ghana's premier tech shop — iPhones, MacBooks, Apple Watches, Accessories.

## Built With
- Pure HTML/CSS/JS (no framework) — GitHub Pages hosted
- Apple Liquid Glass design system
- Firebase Firestore (order management)
- Formspree (email notifications)
- WhatsApp integration

## Features
- Mobile-first Apple liquid glass UI
- Full iPhone SE → 17 Pro Max catalog
- Laptops, Apple Watches, Accessories
- Shopping cart (localStorage)
- Order form → email + WhatsApp + Firestore
- Admin dashboard (orders, status, prices)
- Floating WhatsApp button

## Setup Required
1. Create Firebase project → add config to all HTML files
2. Create Formspree account → add endpoint to `assets/js/app.js`
3. Add CNAME at Porkbun → `@` → `elson222.github.io`
